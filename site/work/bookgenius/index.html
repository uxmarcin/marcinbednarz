Other work, BookGenius, subscription learning app

A trial guide in place of a paywall

BookGenius is a subscription learning app with active recall, quizzes, flashcards and audio summaries. I redesigned the moment when a user is asked to start the free trial. I also planned what happens to users who skip it.

Status
Deployed
Result
+35% conversion
Starting point

Users skipped the paywall

Users were asked to start the trial on a paywall screen. Hotjar showed users skipping it. I set two goals. The app should explain the trial before it asks for it. And I wanted a plan for users who tap Not now.

Step one

A guide that explains the trial first

In place of the paywall I designed a trial guide. It explains how the trial works: 7 days of access, a reminder 2 days before the end, and a simple way to cancel. I wanted users to know the rules before they decide.

Step two

Three strategies for users who tap Not now

For users who skip the trial I described three strategies.

Soft Entry, the existing flow

The user goes into the app.

Value Wall

A one-time offer before the app: 50% off for 3 months, a free month, or free access for inviting friends.

Value Tease

The user explores the app. Some features are locked until the trial starts.

Diagram of the flow. Not app screens.
The decision

Test the Value Wall against Soft Entry

I recommended an A/B test of the Value Wall against Soft Entry. Soft Entry is the existing flow, so it was the control. The test changed only what happens after Not now. The offer is shown once.

+35%conversion
Result

The new flow was deployed

The new trial screen and the A/B test were deployed. The result was +35% conversion.
